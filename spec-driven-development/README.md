# Spec Driven Development

Use these skills in the numbered order for substantial implementation work:

1. `01-plan/repository-implementation-planner`: inspect the repository and write a read-only plan.
2. `02-assessment/implementation-spec-assessor`: assess the plan and its execution contracts.
3. Get explicit user approval for the plan version and scope.
4. `03-execution-and-verification/implementation-plan-executor`: implement approved phases and verify their results.

For a small, direct implementation request, use the normal implementation workflow without the full sequence.
